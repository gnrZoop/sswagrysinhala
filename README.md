## 📖 විස්තරය

මෙම ව්‍යාපෘතිය නිර්මාණය කර ඇත්තේ **ජපානයේ කෘෂිකර්ම, භෝග වගාව සහ පශු සම්පත් (Agriculture, Crop Farming & Livestock)** යන ක්ෂේත්‍රවල විභාගවලට මුහුණ දෙන සිංහල කම්කරුවන්ට සහාය වීම සඳහාය. එය සමාජ සත්කාරයක් (Social Service) ලෙස සංවර්ධනය කර ඇති අතර, විභාගයේ ජපන් භාෂා කොටස පහසුවෙන් සමත් වීමට අවශ්‍ය මූලික දැනුම නොමිලේ ලබා දීම එහි අරමුණයි.

### 🎯 ප්‍රධාන අංග

*   **සම්පූර්ණ පාඩම් මාලාව:** ජපන් හිරගන, කතකන, ඉලක්කම්, වේලාව, දින දර්ශනය, ගණන් කිරීම් යනාදී මූලික සිට කෘෂිකාර්මික නාමපද, ක්‍රියාපද, නාමවිශේෂණ දක්වා විහිදෙන පාඩම් 58කට අධික සංඛ්‍යාවක්.
*   **විභාගානුකූල අන්තර්ගතය:** "農業技能測定試験" (Agricultural Skill Assessment Test) සඳහා වන නිල පෙළ පොත පදනම් කරගෙන සකස් කර ඇත.
*   **සවන්දීමේ පුහුණුව:** විභාගයේ ශ්‍රවණ කොටස සඳහා විශේෂයෙන් නිර්මාණය කරන ලද ප්‍රශ්නාවලියක් (Listening Practice) ඇතුළත්.
*   **ප්‍රායෝගික අභ්‍යාස:** එක් එක් පාඩම අවසානයේ අභ්‍යාස (れんしゅう) මගින් ඉගෙන ගත් දේ තහවුරු කර ගත හැක.
*   **සිංහල පැහැදිලි කිරීම:** සියලුම අන්තර්ගතය සරල සිංහලෙන් පැහැදිලි කර ඇති අතර, ජපන් අක්ෂර සහ උච්චාරණ සඳහා සිංහල ශබ්ද කිරීම් ද ඇතුළත් වේ.

## 🚀 භාවිතා කරන ආකාරය

1.  ඉහත වෙබ් අඩවියට පිවිසෙන්න.
2.  අවශ්‍ය පාඩම මත ක්ලික් කරන්න.
3.  අක්ෂර මාලාව, වචන මාලාව, ව්‍යාකරණ රටා සහ උදාහරණ හොඳින් කියවන්න.
4.  එක් එක් කොටස අවසානයේ ඇති අභ්‍යාස මගින් දැනුම පුහුණු කරගන්න.
5.  **සවන්දීමේ පරීක්ෂණය** (Listening Test) හරහා විභාග රටාවට හුරු වන්න.
